## 💡 【評判 Q\&A 貓紙 (遇到問題照讀)】

- **Q: 點計出專注度？**
  - **A**: 腦波儀收集 Raw EEG，分析 Beta波 (專注) 同 Alpha波 (放鬆) 比例，再經 Python 轉成 0-100 指數傳畀網頁。
- **Q: 點解呼吸訓練得 12 秒？**
  - **A**: 太長會令玩家煩躁 (有挫敗感)。12 秒剛好夠做一個深呼吸循環，目的係「快速重置狀態」然後即刻繼續。
- **Q: Simulation 模式會唔會造假？**
  - **A**: 絕對唔會。Simulation 係為咗確保冇硬件環境下，都能穩定展示「介入機制」(跌 Watt 就引發呼吸)。核心代碼同接駁真實 EEG 係完全一樣嘅。
- **Q: 對 ADHD 真係有用？**
  - **A**: 傳統 ADHD 訓練靠神經回饋 (Neurofeedback)，我哋將佢遊戲化，提供一個低成本、高互動嘅日常工具，幫學生建立「自我覺察」能力。
