## 【展示主軸】

- **主問題**：數碼誘惑同短片內容令年輕人專注力越來越碎片化。
- **主解法**：用 EEG / 外界偵測即時觀察專注狀態，再用遊戲回饋同呼吸介入幫助用戶重新回到穩定專注。
- **主價值**：唔再係叫用戶「你專心啲」，而係令佢即時見到自己狀態、學識點樣拉返自己入狀態。
- **主定位**：神經回饋訓練平台原型，不是單純遊戲，不是單純 EEG 顯示器。

## 【網站所有模式：目的與原理】

### 1. 任務模式

#### `訓練模式`

- **目的**：練基本功，讓用戶在無題目壓力下學習穩定專注。
- **玩法**：船一直向前，用戶只需要維持穩定狀態。
- **顯示重點**：倒數計時、專注穩定、跌 Watt 時會被呼吸訓練拉返入狀態。
- **最適合台上展示**：因為流程最清楚、最穩。

#### `挑戰模式`

- **目的**：模擬真實生活中「一邊做事、一邊專心」。
- **玩法**：加入 Stroop 題同邏輯題，測試玩家在認知負荷下維持專注的能力。
- **顯示重點**：答題壓力、認知負荷、分心與表現下降。
- **最適合台下展示**：因為可讓評判親身感受「做任務時大腦容易亂」。

### 2. 訊號來源模式

#### `Real EEG`

- **目的**：接入真實腦波，展示系統不是假模擬，而是可讀取真實神經訊號。
- **原理**：MindWave 頭帶讀取 EEG，經 `eeg_bridge.py` 轉成 WebSocket 資料，再推送給前端。
- **展示意義**：最有科技感，最吸引評判。
- **風險**：最容易受藍牙、配對、COM port、瀏覽器環境影響。

#### `Simulation`

- **目的**：即使無頭帶或頭帶失靈，仍可完整展示產品邏輯。
- **注意**：Simulation 不是假裝自己係 EEG，而是展示神經回饋系統的「完整運作邏輯」。

##### `Simulation -> Camera Ready`

- **目的**：如果相機開到，就用視覺追蹤去做一個較有互動感的 focus score。
- **原理**：系統會觀察玩家有冇望開、眨眼太頻密、臉有冇保持穩定居中，然後換算成專注分數。
- **展示時講法**：這條路線屬於「外界偵測專注力」。

##### `Simulation -> Fallback`

- **目的**：如果連相機都開唔到，系統仍然要能跑。
- **原理**：系統會用內建的 focus profile 模擬專注上升、下跌、恢復，從而驅動船速和 Box Breathing 介入。
- **展示時講法**：這條路線屬於「展示用保底模式」，確保任何裝置都可 demo。

### 3. Box Breathing 介入層

- **定位**：Box Breathing 唔係某一種獨立模式，而係橫跨整個系統的「介入機制」。
- **何時會出現**：無論前面用緊 `Real EEG`、`Simulation Camera Ready` 定 `Simulation Fallback`，只要系統判定用戶長時間偏離穩定專注狀態，都可以觸發。
- **目的**：當用戶太分心、太急、太亂時，唔係只提示佢做錯，而係即時俾一個可執行嘅 reset 方法。
- **項目意義**：因為我哋目標唔只係「檢測專注」，而係「改善專注」。所以未來除咗 Box Breathing，亦會考慮加入更多改善專注的方法，例如個人化節奏引導、更多類型短介入、長期 progress tracking 等。

### 4. 難度模式

- **Easy**：新手體驗，讓玩家先感受系統如何回應專注變化。
- **Medium**：中等認知壓力。
- **Hard**：高認知負荷，最適合講「現實世界不是靜坐，而是高壓下仍要保持清晰」。

## 【台下攤位示範 SOP】

### Step 1：Hook

- 接待同學：
  - 「評判你好，頭先台上講嗰套腦波訓練系統，我哋而家可以畀你親身試。」

### Step 2：先講網站模式

- 開始前唔好即刻戴頭帶，先用 10 至 15 秒講清楚：
  - 「我哋網站係先揀任務模式，再揀訊號來源模式。即係先決定要練基本功定壓力下專注，再決定用真實 EEG 定 Simulation。」

### Step 3：先示範 `訓練模式`

- **最合理順序**：`Real EEG -> 訓練模式`
- 講法：
  - 「我而家先示範基礎版。呢個模式唔出題，純粹訓練你點樣穩定維持專注。」

### Step 4：再示範 `挑戰模式`

- 講法：
  - 「當基本功穩定後，第二步就係加入任務壓力。呢個模式更加貼近現實，因為真實世界唔係靜坐，而係做緊事都要保持清晰。」

### Step 5：最後展示 `Results`

- 講法：
  - 「每次訓練後，系統都可以量化今次表現，包括穩定度、恢復速度同呼吸介入次數。未來如果做長期訓練，呢類數據就係證明改善嘅基礎。」

### Step 6：講未來發展時只需點到即止

- 「之後我哋希望加入長期 progress tracking、個人化難度調節，同更多外界偵測方式。」

### 突發救場

- 如果 EEG 失敗：
  - 「會場藍牙干擾比較大，Real EEG 正在重連。不過我哋個系統有 Simulation 路線，可以即刻展示完整訓練邏輯。」

## 【評判 Q\&A】

- **Q：你哋個網站點解要有咁多模式？**
  - **A**：因為我哋解決嘅唔只係展示問題，而係訓練問題。系統係先揀 `訓練模式 / 挑戰模式` 去決定練習目標，再揀 `Real EEG / Simulation` 去決定訊號來源。前者解決練咩，後者解決點樣量度。
- **Q：Simulation 會唔會即係假？**
  - **A**：唔係。Simulation 係展示和備援路線，用來保證任何裝置都可以完整示範系統邏輯。真實 EEG 仍然是另一條獨立輸入路線。
- **Q：Simulation 入面兩條路線有咩分別？**
  - **A**：如果相機可用，系統會用相機做外界偵測；如果相機不可用，系統會用 fallback profile 去保證示範流程完整。
- **Q：點解 Box Breathing 有用？**
  - **A**：因為當用戶過度緊張或者太散時，規律呼吸可以幫佢短時間重置節奏，令佢更容易重新回到穩定專注狀態。更重要係，Box Breathing 唔係只跟某一種輸入模式綁死，而係可以接喺所有專注偵測機制後面，作為統一的介入層。
- **Q：你哋點證明真係有效？**
  - **A**：現階段我哋已經做到即時神經回饋、呼吸介入同單次 session 量化；至於長期成效，我哋下一步會做前後測、持續追蹤同 progress report。現階段定位係訓練平台原型，而唔係已完成臨床驗證嘅醫療產品。
- **Q：呢個係咪醫療產品？**
  - **A**：目前唔係。我哋定位係教育 / 訓練 / 神經回饋原型，用來幫用戶建立自我覺察同專注調節能力。
