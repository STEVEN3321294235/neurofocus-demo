## 1. 兩種測試模式（核心）

| | 完整測試 | 快速體驗 |
|---|---|---|
| 用途 | 試行、收數據 | 攤位、錄影示範 |
| 總時間 | 約 5 分鐘 | 約 1 分鐘 |
| 每段長度 | 90 秒 × 2 | 20 秒 × 2 |
| 記錄數據 | 會 | 唔會，畫面標明「示範」 |

### 1.1 完整測試（問題：手機放喺枱面，會唔會令我更難專注？）

流程：
1. 輸入參加者編號（P1、P2……，唔准輸入真名）
2. 戴機，檢查訊號：要連續 5 秒「訊號良好」先可以繼續
3. 練習 20 秒，唔計分
4. 靜坐 30 秒，記錄當天狀態
5. 情況一：90 秒測試 → 問「剛才你覺得自己有多專心？」（1 至 10 分）
6. 轉換 30 秒：畫面講清楚要點樣擺手機，例如「請將手機交俾同學帶出房間」，準備好先撳「繼續」
7. 情況二：90 秒測試 → 同一條自評問題
8. 入結果頁

規則：
- 「手機喺枱面」同「手機唔喺度」邊個先做，要**隨機決定**，並且記錄低
- 兩次都用**同一套固定題目**，唔用 AI 出題
- 測試期間**關閉呼吸提示**，訓練模式就照舊保留

### 1.2 顏色文字題（Stroop）

- 用挑戰模式現有嘅顏色文字題畫面同顏色。每題只顯示一個字，學生要揀**字嘅顏色**，唔係字本身。
- 用一個固定 seed 生成 120 題題庫：4 種顏色，一半顏色同字一致，一半唔一致。每次測試由第 1 題開始出。
- 答題用 4 個大按鈕，或者鍵盤 D、F、J、K。答完即刻出下一題，每題最多 3 秒，超時當答錯。
- 每題記錄：題號、一致定唔一致、有冇答啱、反應時間（毫秒）。
- 3D 海洋場景留喺背後做背景，船速照跟專注分數變化。

### 1.3 快速體驗（1 分鐘）

1. 戴機或者開相機
2. 頭 20 秒：「望住畫面，專心答題」
3. 後 20 秒：「而家望開你部手機」
4. 畫面即時顯示一條專注線，用兩隻顏色分開前後兩段
5. 最後一張結果卡：「你望手機嗰陣，專注線跌咗」，或者「兩段差唔多」

全程角落標「示範模式：唔會記錄做實驗數據」。

## 2. 讀埋原始腦電波數據

而家 `eeg_bridge.py` 只讀廠商嘅專注分數（0x04）同訊號（0x02），8 個頻段數值（0x83）直接跳咗。

**Bridge**：
- 喺 `parse_payload` 加讀 0x83：每個頻段 3 bytes、big-endian，共 8 個，次序係 delta、theta、lowAlpha、highAlpha、lowBeta、highBeta、lowGamma、midGamma
- 喺 websocket 訊息加一個 `bands` 欄位。舊欄位保持不變，舊版前端收到都唔會出錯
- 寫一個細 Python 測試，用假 bytes 證明解析正確

**前端**：
- 每秒計一個自家指標：`(lowBeta + highBeta) / (theta + lowAlpha + highAlpha)`
- 只計算訊號 ≥ 70 嗰幾秒。如果一段 90 秒入面少過 60 秒有良好訊號，結果頁就寫「呢次腦電波訊號唔夠穩定，腦電波結果唔計」，但答題表現同自評照樣顯示

## 3. 結果頁：「你的答案」

- 頂部：條問題
- 一句結論，按數據自動生成：
  - 有明顯分別（答對率差 5 個百分點或以上，或者反應時間差 8% 或以上）：「手機唔喺度時，你答啱多咗 X 題，平均快咗 Y 秒。」
  - 冇明顯分別：「兩次差唔多，今日手機對你嘅專注冇明顯影響。」
- 細字：「呢個只係你今日嘅一次比較，唔代表所有人。」
- 三行比較，每行兩條長條（藍色：手機喺枱面；金色：手機唔喺度）：
  1. 答題表現：答對率、平均反應時間
  2. 腦電波：專注分數平均值、自家指標平均值
  3. 自己感覺：1 至 10 分
- 三樣方向一致，顯示「三樣結果一致 ✓」；唔一致，顯示「三樣結果唔一致，可以再試一次」
- 匯出 CSV：
  - 一個總結檔，每次測試一行
  - 一個逐秒檔：秒數、情況、專注分數、訊號、8 個頻段、自家指標
  - 一個逐題檔
  - 檔名用參加者編號，唔准有真名

## 4. 全站字句重寫

範圍：`app/i18n.js` 所有字句，同埋寫死喺頁面嘅字。

**原則**
- 用中學生聽得明嘅說話，每句只講一件事
- 語氣好似朋友提你，唔好似說明書
- **中英分明**：中文版全句中文，英文版全句英文，同一句入面唔准中英夾雜（「NeuroFocus」除外）。切換語言之後，唔可以有漏翻譯嘅字
- 中文以書面語為主，可以有少少口語；英文用簡單句

**術語改寫**

| 舊 | 中文 | 英文 |
|---|---|---|
| EEG / 腦電 | 腦電波頭帶 | brainwave headband |
| eSense / Attention | 專注分數 | focus score |
| Signal quality | 訊號 | signal |
| Stroop | 顏色文字題 | color-word test |
| Neurofeedback / 神經回饋 | 即時回饋 | live feedback |
| Recovery time | 拉返專注用咗幾耐 | time to refocus |
| Session | 一次測試 | test |
| Simulation | 示範模式 | demo mode |

**重點字句**（照用，或者按同一語氣微調）

| 位置 | 中文 | 英文 |

## 5. 外觀：「實驗筆記簿」

只改**首頁、Setup、測試畫面上嘅資訊面板、結果頁**。3D 海洋場景唔郁，其他頁面照舊。

- 背景用紙色 `#F5F2EA`，加淡方格線；文字用墨黑 `#1A1D21`；重點同腦電波線用橙色 `#E0552B`
- 兩種情況固定兩隻顏色：手機喺枱面用藍 `#2F5BD3`，手機唔喺度用金 `#C98A1B`
- 唔用漸變、發光、玻璃效果、陰影，改用 1px 細線分隔
- 數字用等寬字。英文字型用 IBM Plex Sans 同 IBM Plex Mono，要下載落 `/vendor/fonts` 自存；中文用系統字
- 測試畫面上嘅資訊面板改用實色半透明底，**唔准用 blur**（Windows 整合顯卡會跌 FPS）
- 動畫只做四種，全部只准郁 transform 同 opacity：
  1. 首頁一條慢慢流動嘅腦電波線，標明「示範」；離開畫面就停
  2. 結果頁嘅長條由零生長
  3. 數字由零跳到實際值
  4. 快速體驗嘅即時專注線
- 電腦設定咗「減少動態效果」嘅話，所有動畫要即刻完成
- 首頁刪除寫死嘅「86%」同「SIGNAL STABLE: 12ms」
- 首頁結構：大標題、兩個按鈕、三步流程、誠實聲明同私隱三點（自己決定、數據屬於你、只同自己比較）
